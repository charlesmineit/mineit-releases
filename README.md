# MineIt for Windows

MineIt records buyer claims from your Facebook Live and writes the orders
into your own Google Sheet.

This page holds the MineIt installers only.

## Download

1. Open **Releases** (on the right of this page, or
   [the latest release](https://github.com/charlesmineit/mineit-releases/releases/latest)).
2. Under **Assets**, download `MineIt-Setup-<version>.exe`.
3. Open the file and MineIt installs itself. No administrator password is
   needed.

Needs Windows 10 or 11 (64-bit) and a MineIt licence key.

**"Windows protected your PC"?** A new version can show this for its first
downloads. Click **More info**, then **Run anyway**. Download MineIt only
from this page.

## Updates

MineIt updates itself. A new version downloads in the background and
installs when you close MineIt, never during a live.
